  Kenapa angkanya beda-beda: itu port di LAPTOP. Di dalam jaringan Docker
  aplikasi tetap di 80, MySQL tetap di 3306, SonarQube tetap di 9000.
  Port laptop digeser supaya tidak bentrok dengan hal lain yang sudah jalan.
  Format di Docker selalu  port_laptop : port_container.

     ./run.sh mysql

 Kredensialnya dibaca dari environment container, jadi tidak pernah masuk
 riwayat shell. Itu juga jawaban yang bagus kalau asesor menanyakannya.

 4. MENYALAKAN SEMUANYA
--------------------------------------------------------------------------------

     ./run.sh start        aplikasi + database   (tunggu "Application is up")

 Kalau Docker Desktop mati setelah restart laptop: buka Docker Desktop dulu,
 tunggu ikon pausnya tenang, baru jalankan ./run.sh start.
